Privacy Policy

Tomas Video · Last updated 7 November 2026

Who uses this app

Tomas Video is a private tool used only by its owner. It is not available to the public.

What it accesses

With the owner's permission, the app uses the Google Drive API to upload videos and photos into folders in the owner's own Google Drive. It reads the names of those folders so it can file uploads in the right place. It does not access any other user's Google account.

What it stores

Media sent to the owner's private Telegram group is saved to the owner's Google Drive. Basic details (the caption, the sender's display name, and the date) are kept in a list in the same Drive folder. Files are stored only briefly on the app's server while they are being uploaded, then deleted.

Sharing

No data is sold, shared with third parties, or used for advertising. Google user data is used only to provide the features above, in line with the Google API Services User Data Policy, including its Limited Use requirements.

Removal

The owner can revoke access at any time at myaccount.google.com/permissions and delete the files from Google Drive.
